Kenapa tanpa paging

13 modul dan 11 perintah — di bawah ambang 25 baris pola daftar statis keluarga AWCMS. Paging justru menyembunyikan baris yang dicari.

Pencarian di klien

Data dibangun statis saat build; pencarian dan saringan hanya menyembunyikan baris (progressive enhancement), tanpa panggilan API dan tanpa origin CSP baru.

Satu sumber kebenaran

Deskripsi dan profil dibaca dari metadata MODULE_* repo OMES saat build, bukan disalin tangan — agar tidak basi seperti salinan README.
